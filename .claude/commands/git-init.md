\# /git-init



\## Передумови

\- Поточний каталог є кореневим для проєкту.

\- Git встановлений (`git --version` працює).



\## Дії

1\. Якщо немає каталогу `.git`, виконати `git init`.

2\. Якщо `.gitignore` відсутній, створити його.

3\. Додати в `.gitignore` лише ті рядки, яких там ще немає:

&#x20;  `build/`, `out/`, `.vs/`, `.vscode/`, `.idea/`, `\*.o`, `\*.obj`, `\*.exe`, `\*.pdb`.

4\. Показати `git status --short` і `git branch --show-current`.



\## Очікувані файли

\- `.git/`

\- `.gitignore` із рядком `build/` (рівно один раз)



\## Команди перевірки

\- `git rev-parse --is-inside-work-tree` повертає `true`

\- `git check-ignore build/` повертає `build/`



\## Повідомлення про помилку

\- Git не встановлений: `FAIL git-init: git не знайдено. Встановіть Git і повторіть.`

\- Не вдалося записати `.gitignore`: `FAIL git-init: немає доступу до .gitignore.`



\## Ідемпотентність

Повторний запуск нічого не дублює й не перезаписує: додаються тільки відсутні рядки.



\## Успіх

Вивести `OK git-init` і поточний стан Git.
