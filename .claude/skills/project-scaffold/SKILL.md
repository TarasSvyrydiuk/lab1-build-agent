\# project-scaffold



\## Призначення

Створити початковий каркас проєкту: каталоги, Hello World, README, .gitignore.



\## Вхід

\- `language` — мова (для цього варіанта: `cpp`)

\- `project\_name` — назва проєкту



Приклад входу: `language=cpp, project\_name=hello`



\## Дії

1\. Перевірити, що `language` підтримується (`cpp`). Інакше зупинитись із помилкою.

2\. Створити каталоги `src/`, `tests/`, `docs/`, якщо їх немає.

3\. Створити `src/main.cpp`, якщо його немає:

&#x20;  ```cpp

&#x20;  #include <iostream>



&#x20;  int main() {

&#x20;      std::cout << "Hello, World!" << std::endl;

&#x20;      return 0;

&#x20;  }

&#x20;  ```

4\. Якщо `README.md` порожній або без розділу про запуск, додати розділ

&#x20;  "Складання і запуск" (не перезаписувати наявний вміст).

5\. Додати в `.gitignore` лише ті рядки, яких там ще немає:

&#x20;  `build/`, `out/`, `.vs/`, `.vscode/`, `.idea/`, `\*.o`, `\*.obj`, `\*.exe`, `\*.pdb`.



\## Вихід (очікувані файли)

\- `src/main.cpp`

\- `README.md`

\- `.gitignore` (містить `build/`)

\- каталоги `src/`, `tests/`, `docs/`



\## Перевірки

\- `src/main.cpp` існує й містить `main`.

\- `README.md` містить команду запуску.

\- `.gitignore` містить `build/` рівно один раз.

\- Повторний запуск не змінює файли (ідемпотентність).



\## Типовий сценарій помилки

\- \*\*Помилка:\*\* `language=python`, а skill підтримує лише `cpp`.

\- \*\*Реакція:\*\* повідомлення "FAIL project-scaffold: мова 'python' не підтримується.

&#x20; Доступно: cpp", файли не створюються.

\- \*\*Помилка 2:\*\* `src/main.cpp` уже існує з іншим вмістом. Файл не

&#x20; перезаписується, виводиться "SKIP: src/main.cpp вже існує".
